## 部署静态验收

1. `deploy/compose.yaml` 默认只发布 frontend 端口。
2. 数据服务位于 internal 网络，均有健康检查、资源上限、持久卷和日志轮转。
3. Compose 对所有秘密使用必填插值，无默认密码。
4. 后端 JDK 21 多阶段镜像以非 root 用户运行；前端 Node 22 构建后由 Nginx 提供 history fallback 和 `/api` 代理。
5. 恢复脚本在没有 `--confirm-overwrite` 时退出；本验收不得实际执行恢复。
6. HTTPS 示例不包含证书或私钥。

## AI 评测口径

默认报告必须包含 `executionMode`、`realModelExecuted: false`、数据集数量，并将准确率、耗时和 Token 标为未执行。只有操作者设置 `SMARTMALL_EVAL_ALLOW_REAL_MODEL=YES`、服务地址和短时测试 Token 后主动运行 `run_real_model.py`，报告才可标记真实模型已执行。

## 安全扫描

只扫描 Git 跟踪文件和 Git 历史，输出文件名或 commit/path，不输出疑似秘密文本；不要读取被忽略的 `.env`、`application-local.yml` 或本地凭据。发现疑似真实秘密时先撤销/轮换，再清理历史。
