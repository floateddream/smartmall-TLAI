# SmartMall TLAI 本地启动指南

本文用于记录本地开发时的启动、访问和关闭步骤。项目采用前后端分离结构，因此后端和前端需要分别启动。

## 1. 启动前检查

本地需要具备：

```text
JDK 21
Maven 3.9.16
Node.js 22
pnpm 10
IntelliJ IDEA
```

PostgreSQL 和 Redis 运行在服务器 Docker 容器中。通常不需要在本地启动数据库，但服务器容器和网络必须正常。

## 2. 第一次导入或 POM 修改后

在 IDEA 右侧打开 Maven 面板，点击“重新加载所有 Maven 项目”。

后端父工程是：

```text
D:\software\git\smartmallTLAI\backend\pom.xml
```

所有后端模块都由这个父 POM 聚合管理。

## 3. 配置后端启动项

启动类位置：

```text
backend/smartmall-application/src/main/java/com/smartmall/tlai/SmartMallTlaiApplication.java
```

IDEA 运行配置应为：

```text
JRE：Java 21
模块：smartmall-application
主类：com.smartmall.tlai.SmartMallTlaiApplication
有效配置文件：local
```

“有效配置文件”只填写：

```text
local
```

不要在这里填写 `--spring.profiles.active=local`。如果没有“有效配置文件”输入框，也可以改在“程序实参”中填写：

```text
--spring.profiles.active=local
```

两种方式选择一种，不需要同时配置。

本地配置文件位于：

```text
backend/smartmall-application/src/main/resources/application-local.yml
```

该文件包含本地数据库连接和密钥，不应提交到 Git，也不要把内容贴到公开位置。

## 4. 启动后端

在 IDEA 中运行 `SmartMallTlaiApplication`。

启动过程中会自动执行 Flyway 数据库迁移。因为数据库位于远程服务器，建立连接可能需要等待数秒。

看到以下日志表示后端启动成功：

```text
Tomcat started on port 8080
Started SmartMallTlaiApplication
```

后端地址：

```text
http://127.0.0.1:8080
```

健康检查地址：

```text
http://127.0.0.1:8080/actuator/health
```

正常响应中应包含：

```json
{"status":"UP"}
```

## 5. 启动前端

本机其他项目仍使用 Node.js 18，因此不要修改全局环境变量。打开一个新的 PowerShell 窗口，只在当前窗口临时使用 Node.js 22：

```powershell
cd D:\software\git\smartmallTLAI\frontend

$env:Path = "D:\software\node-v22.23.2;D:\software\node-v22.23.2\npm_global;$env:Path"

node -v
pnpm -v
pnpm dev
```

`node -v` 应显示：

```text
v22.x.x
```

如果当前 PowerShell 找不到 `pnpm`，可以直接执行：

```powershell
& "D:\software\node-v22.23.2\npm_global\pnpm.cmd" dev
```

看到 Vite 输出本地地址后，在浏览器打开：

```text
http://127.0.0.1:5173
```

前端会把 `/api` 和 `/actuator` 请求代理到本地后端的 `8080` 端口。

## 6. 推荐启动顺序

```text
1. 确认服务器 PostgreSQL、Redis 容器正常
2. 在 IDEA 中启动后端
3. 等待后端出现 Started SmartMallTlaiApplication
4. 在 PowerShell 中启动前端
5. 浏览器访问 http://127.0.0.1:5173
```

如果只是修改前端页面，Vite 通常会自动热更新，不需要重启后端。

如果修改了 Java 代码、POM 或 Flyway 迁移文件，通常需要重新启动后端。

## 7. 如何停止

停止后端：点击 IDEA 运行窗口中的红色停止按钮。

停止前端：在运行 `pnpm dev` 的 PowerShell 窗口中按：

```text
Ctrl + C
```

这只会停止本地程序，不会停止服务器上的 PostgreSQL 和 Redis 容器。

## 8. 常见问题

### 8.1 JWT secret must contain at least 32 characters

原因：没有加载 `application-local.yml`。

检查 IDEA 运行配置中的“有效配置文件”是否为：

```text
local
```

启动日志应出现：

```text
The following 1 profile is active: "local"
```

### 8.2 Vite 提示 Node.js 版本是 18

原因：当前 PowerShell 仍在使用系统原有的 Node.js 18。

在同一个 PowerShell 窗口重新执行：

```powershell
$env:Path = "D:\software\node-v22.23.2;D:\software\node-v22.23.2\npm_global;$env:Path"
node -v
pnpm dev
```

这项修改只对当前 PowerShell 窗口生效，不影响其他项目。

### 8.3 Flyway checksum mismatch

原因：数据库已经执行过的迁移文件被修改了，即使只修改注释也会影响校验值。

处理原则：

- 已执行的 `V1`、`V2`、`V3` 不应继续修改。
- 新的数据库结构变化应创建 `V4`、`V5` 等后续迁移。
- 不要在没有确认数据库状态时直接执行 Flyway `repair`。

### 8.4 请求提示 401 或跳回登录页

JWT 已失效、后端刚重启或浏览器保存了旧令牌时，重新登录即可。

### 8.5 后端连接数据库较慢或超时

先通过 Xshell 登录服务器，执行：

```bash
docker ps
```

确认 PostgreSQL 和 Redis 容器处于 `Up` 或 `healthy` 状态，同时检查腾讯云安全组和本地网络。
