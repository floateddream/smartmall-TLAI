# 项目截图清单

公开展示前使用专用演示数据，遮盖账号邮箱、客户电话、订单地址、令牌、密钥、内网地址和浏览器开发者工具中的 Authorization Header。

| 序号 | 页面/场景 | 截图重点 |
|---|---|---|
| 1 | 登录页 | 品牌、登录校验，不展示真实账号 |
| 2 | 仪表盘 | 经营指标、趋势、服务状态 |
| 3 | 订单详情 | 商品项、金额、状态时间线 |
| 4 | 退款审核 | 申请原因与状态流转，隐藏个人信息 |
| 5 | 售后工单 | 消息记录和优先级 |
| 6 | 模型配置 | 供应商/模型/状态；API Key 输入保持掩码 |
| 7 | 知识库 | 文档状态、分片数量、失败重试 |
| 8 | RAG 回答 | 引用编号和来源抽屉 |
| 9 | Agent 查询 | 工具摘要和安全业务跳转 |
| 10 | 写操作确认 | `ACTION_CONFIRMATION` 卡片，遮盖 token |
| 11 | Agent 审计 | 参数键、状态、耗时、trace 关联 |
| 12 | AI 调用日志 | 模型、场景、规模、耗时，不含正文 |
| 13 | 权限管理 | 角色权限矩阵与禁用用户 |
| 14 | 部署验收 | Compose 健康状态，只展示服务名和 health |
| 15 | 评测报告 | `realModelExecuted` 与覆盖数量清晰可见 |

建议统一 1440×900 或 1920×1080、使用同一浏览器缩放比例。截图不是安全证明，应配合测试报告和代码说明。
